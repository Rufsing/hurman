# HURMAN

A third-person neon-noir mercenary game built in **Godot 4.7 .NET (C#)**: gun-fu combat, underworld contracts, and a home base you rebuild from a rented basement.

- **Game design**: [docs/GAME_DESIGN.md](docs/GAME_DESIGN.md)
- **Roadmap / plan**: [docs/PLAN.md](docs/PLAN.md)
- **Planning log**: [docs/plans/](docs/plans/)

## Status
Milestone 1 (vertical slice) in progress: greybox Lowmarket, Fred's basement, first contract loop. See docs/plans/ for the latest log.

## Running
1. Install Godot 4.7 .NET from https://godotengine.org/download
2. Open Godot → Import → select `project.godot` in this folder.
3. Press **F5** to play. (Controls are shown at the bottom of the screen.)
